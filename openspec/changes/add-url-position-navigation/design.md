## Decisions

1. 行号是正整数，仅接受完整十进制字符串和 Int 范围；重复或无效 line 不报错，不影响打开 path。有效行号优先于 fragment。
2. 使用原始文件行号。front matter 移除后的行映射必须加偏移；fence、代码块及自定义渲染器也需保留覆盖范围。隐藏行号栏不影响定位。
3. 优先选择最具体的覆盖块，避免只选第一个起始行大于目标的节点。空白行向后找块，超出末尾定位最后一块，空文档不滚动。
4. 使用 JSON/结构化 JS 参数传递目标，避免插值执行用户输入。
5. 复用现有打开文件和锚点机制，但请求必须绑定标准化文件 URL 及最新渲染版本。等待实际渲染完成，不用固定延时猜测。显式目标一次消费后不反复覆盖用户滚动。
6. 已打开文件须主动通知对应视图；不存在的文件仍走现有打开错误处理。

## Validation

先写失败测试，再实现。覆盖普通段落、列表、表格、代码块、front matter 偏移、空白行、首尾、越界、无效/重复参数、中文与百分号路径、注入字符串、锚点优先级、已打开文件、多文件并发、重载以及历史滚动恢复。App 运行包验证后进入版本排期。
