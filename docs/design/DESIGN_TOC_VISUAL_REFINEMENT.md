# 目录视觉融合调整

用户反馈：侧栏与正文风格不一致，灰色底板与直线边界显得突兀。本次为现有目录的视觉细化，保持目录宽度、停靠/浮层切换、导航和持久化行为。

## 视觉方案

- 停靠目录与正文共用背景，移除整块灰色底板及标题横线；通过留白和上下渐淡的细线建立层次。
- 标题使用低强调文字，关闭按钮变成无边框圆形控件，与原生顶部圆形工具协调。
- 当前章节使用低饱和浅色底和短竖线，普通项以文字层级表达结构，避免大面积亮蓝色块。
- 窄窗口浮层保留必要的独立底色，采用柔和圆角和分层阴影；左右停靠对称。
- 保留清晰的键盘焦点；减少动态效果偏好下禁用过渡。

## 实现前验收标准

在真实 WebKit 中截图检查 1280/900/760 CSS px、浅/深色及左侧停靠。常驻目录无实心灰色大底板、顶部横向硬边和方框关闭按钮；正文宽度与原来相同。目录长标题仍截断可读，长目录可滚动；活动项、悬停、焦点均可辨认；窄窗口浮层不越界，关闭后正文恢复全宽。现有目录、阅读工具和导出回归测试须通过。


## 验证结果

- 目录、侧栏集成、阅读工具和导出相关 5 组测试共 38 个用例通过；TypeScript 检查和生产构建通过。
- 真实 WKWebView 检查 1280/900/760 CSS px、深浅主题、左侧停靠与长目录滚动共 7 种状态。停靠导航背景透明、无实体边框；浮层保持可辨认边界，全部位于视口内。
- 截图位于本地 build/toc-visual，旧版对照位于 build/toc-visual-before。深色截图同时设置原生 NSAppearance 与渲染器主题，匹配 App 的实际运行方式。
- 本次调整为样式细化，不修改正文宽度、导航状态机或发布版本。
