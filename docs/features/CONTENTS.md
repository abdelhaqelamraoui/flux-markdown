# 常驻目录与阅读工具

主应用和展开的 QuickLook 预览中，有标题的文档会提供顶部“目录”按钮。
宽窗口默认在正文右侧显示目录，正文为其预留空间；点击按钮或面板的关闭按钮可收起。
在“设置 → 外观 → 目录位置”可以选择左侧或右侧，选择会保存；目录入口始终跟随面板所在侧。
默认右侧入口与现有顶部功能区相邻，并留有小段间距。

窗口较窄时，目录默认关闭。点击顶部入口临时打开，选择章节后自动收起；点击正文也可关闭。
主应用中还可以用 Esc 收起临时目录。QuickLook 保留系统键盘行为。

正文滚动时目录会标记当前章节。较长的目录可以单独滚动，长标题可悬停查看全文。
改变窗口宽度或重载同一文档不会清除宽窗口的目录显隐选择；窄窗口的临时开关不会改写这个选择。
显隐选择只保留在当前文档视图会话内。

包含引用块的文档还会在顶部显示“折叠引用块”按钮；没有标题或引用块时，对应入口自动隐藏。
空间足够时，目录和引用块按钮与原有顶部工具共用一行；空间不足时才紧凑换行。
搜索栏恢复为正文上方的居中浮动面板，展开和收起都不挤占正文高度或改变阅读位置。

Finder 紧凑预览栏保持简洁，不显示目录工具。打印、PDF 和 HTML 导出不保留目录或工具占位；
折叠的引用内容在输出时完整展示。

宽窗口使用 240 CSS px 的右侧目录，可用内容视口至少 900 CSS px 时停靠；缩放改变文档字号，
目录不遮盖正文。当前版本不提供宽度拖拽；目录位置跨次启动记忆，显隐只在当前文档视图会话内记忆。
